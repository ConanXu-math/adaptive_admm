# M-ADMM vs 经典ADMM：闭环可行性分析

## 一、问题澄清

### 当前情况
- **论文1607.02584**：M-ADMM（Mixed Gauss-Seidel and Jacobian ADMM）
- **funsearch生成的代码**：经典ADMM（Gauss-Seidel顺序更新）
- **形式化定义**：经典ADMM（AdaptiveScheme.lean）
- **目标**：经典ADMM的自适应参数搜索 + 形式化验证收敛

### 核心问题
**能否用M-ADMM的数值实验结果来验证经典ADMM的自适应参数策略，并形成闭环？**

## 二、M-ADMM vs 经典ADMM 关键差异

### 1. 更新策略差异

| 特性 | 经典ADMM | M-ADMM |
|------|---------|--------|
| **更新方式** | 完全顺序（Gauss-Seidel） | 混合：组内并行，组间顺序 |
| **变量分组** | 两变量块（x₁, x₂） | 多变量块，分组处理 |
| **信息利用** | 使用最新值 | 部分使用旧值（Jacobian部分） |
| **收敛保证** | 两块问题收敛性明确 | 多块问题，需要额外条件 |

### 2. 形式化定义对比

#### 经典ADMM（AdaptiveScheme.lean）
```lean
-- 顺序更新
itex₁ : ∀ k, IsMinOn (fun x₁ ↦ L(x₁, x₂ k, y k)) univ (x₁ (k+1))
itex₂ : ∀ k, IsMinOn (fun x₂ ↦ L(x₁ (k+1), x₂, y k)) univ (x₂ (k+1))
```
- x₁使用x₂的**旧值**（k）
- x₂使用x₁的**新值**（k+1）

#### M-ADMM（理论）
```lean
-- 混合更新（假设）
itex₁ : ∀ k, IsMinOn (fun x₁ ↦ L(x₁, x₂ k, y k)) univ (x₁ (k+1))
itex₂ : ∀ k, IsMinOn (fun x₂ ↦ L(x₁ k, x₂, y k)) univ (x₂ (k+1))  -- 注意：使用x₁ k而非k+1
```
- 部分变量使用**旧值**（Jacobian风格）

### 3. funsearch生成的代码分析

查看 `l1_fun.py`：
```python
# 更新顺序
X = prox_l1(Z - Y2 / mu, 1 / mu)  # 使用Z的旧值
Z = invAtAI @ (-A.T @ Y1 / mu + AtB + Y2 / mu + X)  # 使用X的新值
```

**结论**：这是**经典ADMM**（Gauss-Seidel），不是M-ADMM！

## 三、闭环可行性分析

### ✅ 情况1：论文代码是M-ADMM，但funsearch生成的是经典ADMM

**分析**：
1. **参数自适应策略的通用性**：
   - 参数自适应策略（基于残差调整ρ）在M-ADMM和经典ADMM中**可以通用**
   - 因为两者都使用相同的残差定义：`primal_res = A₁x₁ + A₂x₂ - b`
   - 自适应更新规则不依赖于更新顺序

2. **数值实验的适用性**：
   - 如果论文用M-ADMM验证了自适应参数策略的有效性
   - 这个策略**可以迁移**到经典ADMM
   - 因为参数调整逻辑是**算法无关**的

3. **形式化验证的适用性**：
   - 形式化定义是经典ADMM
   - funsearch生成的代码也是经典ADMM
   - **可以直接应用形式化验证** ✅

**闭环路径**：
```
M-ADMM论文实验代码（验证自适应策略有效性）
    ↓ (策略迁移)
经典ADMM + 自适应参数（funsearch生成）
    ↓ (形式化验证)
经典ADMM形式化定义 + Condition C1/C2
    ↓ (收敛保证)

```

**结论**：**可以形成闭环** ✅

### ⚠️ 情况2：论文代码和funsearch代码都是M-ADMM

   - 当前形式化定义是经典ADMM

   - **不能直接应用**当前的形式化定义 ❌

2. **需要的修改**：

**结论**：**需要额外工作** ⚠️

## 四、关键判断：funsearch代码是哪种ADMM？

### 检查更新顺序

从 `l1_fun.py` 看：
```python
X = prox_l1(Z - Y2 / mu, 1 / mu)      # 步骤1：更新X，使用Z旧值
Z = invAtAI @ (..., X)                 # 步骤2：更新Z，使用X新值
```

这是**经典ADMM（Gauss-Seidel）**！

### M-ADMM的特征

M-ADMM应该有以下特征之一：
1. **多块变量**：超过2个变量块
2. **并行更新**：某些变量块并行更新
3. **混合信息**：部分使用旧值，部分使用新值

从代码看，funsearch生成的是**经典ADMM**。
